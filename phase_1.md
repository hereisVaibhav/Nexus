# Phase 1: Project Scaffolding & Design System

## Objectives
- Initialize the React environment.
- Establish a professional design system.
- Setup PWA foundations.

## Tasks
1. **Initialize Project**: Use Vite to scaffold a React + JavaScript project.
2. **Directory Structure**:
   - `/src/components`: Reusable UI elements.
   - `/src/pages`: Main view components (Dashboard, Settings, etc.).
   - `/src/styles`: CSS modules and global variables.
   - `/src/utils`: Helper functions (Gemini API, Storage).
   - `/src/data`: Static content files.
3. **Design System**: 
   - Define colors (primary: deep blue/teal, secondary: soft green).
   - Setup typography (Google Fonts - Inter or Outfit).
   - Create `index.css` with CSS variables.
4. **PWA Essentials**:
   - Create `manifest.json` with app icons.
   - Basic Service Worker registration.
5. **Basic Routing**: 
   - Setup `react-router-dom` for navigation between Dashboard and Details.
